# Enhelo

Página de [enhelo.xyz](https://enhelo.xyz), publicada con GitHub Pages.

## Cómo editar

- **Número de WhatsApp:** en `script.js`, cambia `WHATSAPP` (código de país + número, sin espacios).
- **Agregar una foto a la galería:** sube la foto sin fondo (.webp o .png) a `img/p/` y copia un bloque `<figure>` en `index.html` (sección Galería). Las clases `c1` a `c4` cambian el color del fondo.
- **Productos:** las listas están en la sección Productos de `index.html`.

## Archivos

- `index.html` · página principal
- `style.css` · estilos
- `script.js` · enlaces de WhatsApp
- `img/p/` · fotos de productos sin fondo
- `fonts/` · tipografías
- `404.html` · página de error
- `CNAME` · dominio
